# Explainable AI (XAI) Diagnostic Layer for Aero Piston Engine Digital Twin

## 1. Executive Summary & Purpose
This module implements a real-time, non-intrusive **Explainable AI (XAI)** layer for the MALE UAV Aero Piston Engine Digital Twin system. The four core machine learning models operate as **frozen inference engines** (no retraining, no architecture modifications, no weight updates, and no alteration to prediction logic).

The XAI layer consumes:
1. The exact same feature vectors generated by the real-time feature engine (`DigitalTwinFeatureEngine`).
2. The exact same loaded model objects (`DigitalTwinModelManager`).
3. The model inference outputs.

It provides local feature attribution, sensor-level root-cause diagnostics, transparent confidence indicators, and human-readable engineering explanations for pilots, ground control station (GCS) operators, propulsion engineers, and depot maintenance personnel.

### Model 1: Anomaly Detection (Isolation Forest)
- **Methodology**: **Counterfactual Perturbation Sensitivity & Standardized Z-Score Deviation Analysis**.
- **Rationale**: Isolation Forest partitions feature space via randomized orthogonal splits; it does not output linear gradients or additive margin scores like gradient boosted trees. TreeSHAP on Isolation Forest path lengths does not directly quantify anomalous deviation from the nominal operating envelope.
- **Sensitivity Formula**:
  $$\Delta \text{score}_i = \text{decision\_function}(X_{\text{nominal\_i}}) - \text{decision\_function}(X)$$
  where $X_{\text{nominal\_i}}$ substitutes feature $i$ with its calibrated baseline mean ($z_i = 0$). If feature $i$ is dragging the observation into anomaly territory, setting it back to nominal yields a positive recovery $\Delta \text{score}_i > 0$.
- **Standardized Distance**:
  $$z_i = \frac{x_i - \mu_i}{\sigma_i}$$
- **Wording Standard**: Formulated as *"contributes to the anomalous operating pattern"* rather than prematurely declaring physical mechanical failure.

### Model 2: Degradation Estimation (XGBoost Regressor)
- **Methodology**: **SHAP TreeExplainer** with **Dual-Source Telemetry Routing**.
- **Dual-Source Architecture**:
  - If telemetry ground truth (`degradation` or `health_index`) is provided in the packet, the backend bypasses XGBoost. In this mode, the XAI engine returns `explanation_source: "telemetry"` and validates active sensor health profiles.
  - When model inference executes, `explanation_source: "xgboost"` evaluates SHAP TreeExplainer across the 120 engineered features, attributing wear to specific sensor drifts and volatility trends.

### Model 3: Multiclass Fault Classification (XGBoost Classifier)
- **Methodology**: **Multiclass SHAP TreeExplainer (Log-Odds Decomposition)**.
- Explains feature contributions specifically towards the **predicted class** ($C_{\text{pred}}$).
- Identifies whether each feature increases or decreases the log-odds of the diagnosed fault (e.g. `overheating`, `lubrication_degradation`, `injector_degradation`, `misfire`, `sensor_fault`).

### Model 4: Remaining Useful Life (RUL) (XGBoost Regressor + Dynamic Post-Processing)
- **Methodology**: **SHAP TreeExplainer (Raw XGBoost Prediction) + Explicit Post-Processing Transparency**.
- **Strict Separation**:
  1. **Raw Model Explanation**: SHAP values explain why the raw XGBoost tree booster output `raw_rul_hours` (e.g. 41.7 hrs).
  2. **Post-Processing Explanation**: Details the downstream deterministic filters applied to ensure mission safety:
     - *Dynamic Health Anchoring*: Blends raw ML output with physical health target ($\text{Health\%} \times 50\text{h}$) and enforces zero-clamping at degradation $\ge 0.98$.
     - *EMA Temporal Smoothing*: Low-pass filter ($\alpha = 0.12$) to eliminate sensor jitter.
     - *Slew-Rate Limiting*: Clamps rate of change ($+0.5\text{h/s}$ max rise, $-2.0\text{h/s}$ max drop).
     - *Uncertainty Quantification*: Sub-ensemble boosting-round variance sampling for 90% confidence intervals ($P_{10} - P_{90}$).
  3. **History Warm-up Handling**: When history buffer has $< 13$ frames, returns `status: "COLLECTING_HISTORY"` cleanly without raising exceptions.

## 4. Intelligent Feature Mapping & Sensor-Level Aggregation

The engine features 55 to 131 engineered parameters (derivatives, rolling means, rolling standard deviations, lag terms, physics residuals). The `FeatureMapper` automatically parses prefixes, suffixes, and thermodynamic formulas:

- **Base Sensor Dictionary**: Maps `cht_C`, `egt_C`, `oil_pressure_bar`, `vibration_rms`, `rpm`, etc. to formal engineering designations and units.
- **Mathematical Operation Parser**:
  - `*_slope*` $\rightarrow$ Rate of change / trend over window.
  - `*_diff*` $\rightarrow$ Delta change over $N$ samples.
  - `*_rollmean*` / `*_mean_*` $\rightarrow$ Moving average over recent window.
  - `*_rollstd*` / `*_std_*` $\rightarrow$ Volatility / fluctuation over recent window.
  - `*_lag_*` $\rightarrow$ Prior historical state offset.
  - `*_residual` $\rightarrow$ First-principles thermodynamic physics deviation.
- **Sensor-Level Grouping**: Aggregates all supporting engineered features into overarching subsystem cards (e.g. all CHT slopes, averages, and residuals aggregate into **Cylinder Head Temperature** with combined importance rating `HIGH`, `MEDIUM`, or `LOW`).

## 5. Confidence Calculation Methodology

| Model | Confidence % | Confidence Type | Mathematical Formulation |
| :--- | :--- | :--- | :--- |
| **Fault Classification** | $0\% - 100\%$ | `model_probability` | Exact softmax probability $P(C_{\text{pred}})$ from `predict_proba()` |
| **Anomaly Detection** | $50\% - 98\%$ | `heuristic` | Hyperbolic tangent margin curve: $\text{conf} = 50 + 48 \cdot \tanh(2.5 \cdot |\text{score} - \text{thresh}|)$ |
| **Degradation (Telemetry)** | $98\%$ | `telemetry_based` | Fixed high-confidence rating reflecting verified onboard telemetry |
| **Degradation (Model)** | $50\% - 95\%$ | `model_stability_indicator` | Regressor tree consensus and residual variance indicator |
| **RUL Estimation** | $15\% - 98\%$ | `uncertainty_based` | Exponential relative uncertainty decay: $\text{conf} = \text{clamp}(100 \cdot e^{-1.5 \cdot (\sigma_{\text{RUL}} / \text{RUL})}, 15\%, 98\%)$ |
